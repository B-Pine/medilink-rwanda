# Patient web app (PWA)

Phase-1 patient channel: find facilities, check insurance and cost, book or join today's queue, track position, see visits, prescriptions, documents and receipts, manage dependents, raise disputes.

Planned stack: React 18 + TypeScript + Vite, installable PWA with offline access to bookings, tickets and documents, and web push notifications. Kinyarwanda first, large-type, low-bandwidth. Public facility pages must be indexable by search engines.
