# 09 · Document design (PDFs and printouts)

Status: Research v0.1 · Requirements: FR-DOC-01..07, FR-BIL-08 · Generated with WeasyPrint (ADR 0003)

The documents leave the system: patients show them to pharmacies, employers and insurers. They must look **official, be readable by elderly people, survive cheap printers and photocopies, and be verifiable**.

## 1. Principles (from research and practice)

| Principle | Rule |
|---|---|
| Readability | Critical information ≥ 12 pt; body 10–11 pt; generous white space; high contrast (black/near-black text) |
| Clear sections | Header → who/when → main content → totals/instructions → signature/verification → footer |
| One controlled template per document type | All facilities use MediLink's templates, with their own letterhead, logo and stamp |
| Prominent instructions | Dosage and warnings bold and easy to find (prescription label guidance) |
| **Pictograms** for dosing | Research (including randomised trials) supports pictograms for understanding, especially for low-literacy patients |
| Multilingual | The patient's language for instructions; field labels bilingual (Kinyarwanda / English or French) on official documents |
| Prints in black and white | Colour is decorative only (a thin emerald rule, the logo). Meaning never depends on colour. |
| Verifiable | QR + short code + document number on every document (FR-DOC-04) |
| Accessible PDF | Tagged PDF (headings, reading order, table headers), document language set, real text (not images). Aim for PDF/UA where WeasyPrint allows. |
| Minimal sensitive data | Only what the document's purpose needs. Restricted diagnoses replaced on documents shown to others (FR-CLN-08). |

## 2. Page formats

| Document | Format | Why |
|---|---|---|
| Prescription | **A5 portrait** (A4 option) | Common prescription size; fits a pharmacy counter |
| Sick note / medical certificate | A5 or A4 | Given to employers |
| Visit summary, referral letter, lab request | A4 portrait | More content; formal letters |
| Receipt / invoice | A4, **or 80 mm thermal** at reception | Facilities often have thermal printers |
| Ticket slip | **58 / 80 mm thermal** | Patients without smartphones |
| Insurance claim list | A4 landscape | Wide table |


- **Typography:** the UI typeface (Inter or the final choice) embedded. Title 16–18 pt bold; labels 8–9 pt uppercase muted (`#475569`); values 10–11 pt; numbers tabular.
- **Margins:** 15 mm (A5: 12 mm). A faint Imigongo watermark at 3–4% may sit behind the content. It discourages crude forgery and must not reduce legibility.
- **Superseded versions** carry a diagonal "SUPERSEDED, see version 2" band. Revoked ones carry "CANCELLED". The verification page shows the same status.

## 4. Document-specific designs

### Prescription

```
 #  Medicine                       Dose & how often              Duration  Qty
 1  Amoxicillin 500 mg capsule     1 capsule  ☀ ◐ ☾  (3× a day)   7 days    21
                                   After meals · by mouth
 2  Paracetamol 500 mg tablet      2 tablets when needed          3 days    12
                                   Max 4 times a day
 Generic substitution allowed: Yes
 ⚠ Allergies: Penicillin  ← if any, printed prominently (here it would have triggered an alert)
```

- **Dosing pictograms:** morning ☀, midday ◐, evening, night ☾ (drawn icons, not font glyphs), plus text in the patient's language.
- Dispensing status is not printed (the prescription is the order). The **dispensing record** is a separate document.

### Receipt (A4 and 80 mm)

Sections:
1. Receipt number and date
2. Patient and visit
3. Lines: description, qty, unit price, total, insurer share, patient share; right-aligned, tabular
4. Totals block: total, insurer pays, **patient paid** (largest number), balance
5. Payment method and reference (MoMo transaction ID)
6. Cashier name
7. EBM receipt number if recorded
8. QR

The **80 mm thermal version** uses a single column with the same order, monospace numbers, no watermark and a QR at the bottom.

### Sick note / medical certificate

Short formal text with fields: "…was examined on [date] and requires rest from [date] to [date] ([n] days)." **No diagnosis by default** (privacy); the doctor can opt to include one. Signature, stamp, licence number, QR. This is the document most likely to be forged, so verification is prominent.

### Referral letter

To (facility/specialty), urgency, reason, relevant findings, treatment given, attachments list. The Mutuelle referral context is stated so the receiving facility and the insurer accept it.

### Visit summary (patient copy)

Plain language: "What we found", "What to do", "Your medicines", "Come back if…" (warning signs), "Next visit". A large type option. This is the patient's take-home document.

### Ticket slip (thermal)

```
   KIGALI CLINIC
   ─────────────
      G-023
   General consultation
   14 Oct 2026  08:12
   ~ 25–35 min
   Watch the screen for your number
   [QR → live tracker]
```

## 5. Inspiration and references

- Stripe-style invoice structure: header, parties, details, itemised lines, totals, payment terms. Clean, few rules, generous spacing.
- Minimal invoice practice: remove decorative lines; keep scannable fields.
- Prescription label guidance: clear fonts, adequate size, high contrast, prominent dosage and warnings, pictograms, multilingual text, QR codes.
- Regulatory mandatory fields must be confirmed with the Pharmacy Council / Ministry (open question Q8 in [17](../../analysis/17-assumptions-risks-and-open-questions.md)).
