# Rwanda sectors, cells and villages (NISR codes)

`locations_nisr_2019.csv` lists Rwanda's 416 sectors, 2,148 cells and 14,816 villages with their
NISR codes. It uses the `import_locations` columns (`code,level,parent_code,name`) and is loaded
by migration `masterdata/0004_nisr_locations` (issue #48). Provinces and districts come from
migration 0002, which uses the same codes.

## How the file was made

```
pdftotext -raw List_of_Villages_for_all_technology.pdf nisr_raw.txt
python scripts/convert_nisr_villages.py villages.csv nisr_raw.txt \
    medilink/masterdata/data/locations_nisr_2019.csv
```

The copy has defects from parsing the PDF. The script repairs each defect with a rule:

| Defect | Rows | Repair |
|---|---|---|
| Merged "I/II" cells with no code (Munanira, Nyakabanda, Rwezamenyo, Rukiri, Kabuga, Rugarama) | 67 villages | Cell code = first 6 digits of the village code; the numeral moves from the village name back to the cell (Kabuga I, Kabuga II). This gives 12 real cells. |
| Sector 1110 "RwezamenyoKabuguru", cells named only "I" and "II" | 8 | Sector Rwezamenyo; cells Kabuguru I and Kabuguru II |
| Cell 520204 "GikundamvuraGikundamvura", village names prefixed with the cell | 12 | Cell Gikundamvura; prefix removed |
| Cell 521104: every village starts with "II" | 10 | Cell Rukomo II |
| Villages named only "I", "II" or "III" | 5 | "<cell> II" (for example "Nyabwishongwezi II") |
| Cell 450301 "Bwisige" with garbled village names | 6 | Taken from the PDF: cell Gacurabwenge, villages Gacurabwenge, Gasharu, Gashirwe, Rubyiniro, Ruyaga, Rwasama |
| All sectors of Ngororero, Rulindo and Nyagatare in capitals | 1,541 | Normal capitalisation (BWIRA becomes Bwira) |
| Roman numerals written "Ii", "Iii" | all | Written "II", "III" |

The script stops on any of the following:
- a code that is not under its parent's code;
- a code with two different entries;
- a province or district that differs from migration 0002;
- a village whose code is missing from the PDF, or a code in the PDF that is missing from the list;
- a village whose name and cell are not printed before its code in the PDF.

## Checks on the result

- 416 sectors and 2,148 cells, the same as NISR's official totals.
- 14,816 villages, the same set of codes as the PDF (none missing, none extra). Some other lists
  give 14,837 villages, from a different version of the list.
- Every village's name and cell match the PDF, except 3 rows where the PDF row itself is
  incomplete. In each of the 3, the village keeps the cell its code points to:
  - `11050304` Karambi: the PDF prints cell "Mwendo", but the code is under cell 110503 Mataba.
  - `34110309` Nturoyinkoko: the PDF row has no names.
  - `35080103` Bugarula: the PDF row shows only "Bugarula" and the code.
- 7 cells have two villages with the same name but different codes, for example Kigarama
  24140107 and 24140108. This is also in the NISR PDF, and both villages are kept.
- No parent has more than 25 children, so the wizard's village picker (100 per level) lists all.

Corrections from NISR go through `manage.py import_locations FILE --apply` or the platform
console. Do not edit this file after the migration has run anywhere.
